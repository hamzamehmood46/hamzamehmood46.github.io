Engineering notes

Bugs defeated.

Real bugs that surfaced while building these projects, caught by tests, and what each one taught me.

SQLite · EF Core

The timestamp with no timezone.

SQLite drops DateTimeKind, so dates came back without a Z and browsers read UTC as local time. A value converter fixed it, and a test on the raw JSON keeps it fixed.

ASP.NET Core · records

Validation that silently didn't run.

[Required] on a positional record lands on the constructor parameter, but minimal APIs validate properties. Blank names sailed through until [property: Required].

Concurrency

Ten withdrawals, balance for five.

Optimistic concurrency with reload-and-retry means the rules always run against the latest state. Exactly five win, and the balance never goes negative.

Messaging

One emoji, double the cost.

A single emoji flips an SMS from 160-character GSM-7 to 70-character UCS-2, so a text that fit in one part suddenly needs three. The Twilio console counts parts the way carriers bill them, and tests pin the boundaries.
