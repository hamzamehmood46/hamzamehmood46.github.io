# hamzamehmood46.github.io

Personal portfolio site: a single static `index.html` with no build step and no dependencies. Supports light and dark mode, is responsive down to phone width, and respects reduced-motion preferences.

## Publish with GitHub Pages

This repository is named `hamzamehmood46.github.io`, so GitHub serves it automatically at **https://hamzamehmood46.github.io** once it's pushed to `main` (Settings -> Pages -> Deploy from branch -> `main` / root, if it isn't already enabled).
